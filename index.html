在庫管理システム

JavaScript LocalStorage 検索

商品登録、入荷、出荷、在庫確認、検索をまとめたブラウザ用の在庫管理アプリです。

  • 商品番号、価格、在庫数、入荷日、バーコードを登録できます。
  • 一覧画面から入荷・出荷を行い、在庫履歴を保存できます。
  • 商品検索、在庫不足・在庫切れの絞り込み、低在庫アラートに対応しています。

天気アプリ

天気アプリ

JavaScript API Vercel関数

都市名検索や現在地から天気を表示できる、レスポンシブ対応の天気予報アプリです。 ブラウザ側にAPIキーを出さないよう、小さなAPIプロキシも利用しています。

  • 都市名検索と現在地取得に対応。
  • 7日間予報とOpen-Meteoのフォールバックを実装。
  • 天気情報に合わせた自動テーマ切り替え。

電卓アプリ

科学計算機

式解析 計算 履歴

科学計算機能、角度モード、式の解析、キーボード入力、計算履歴に対応した電卓アプリです。
