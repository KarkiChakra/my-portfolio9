# Karki Chakra Portfolio

Japanese portfolio site for web development practice. It includes the main portfolio page, a resume page, and small browser apps for inventory, weather, tasks, and calculation.

## Pages and Apps

- `index.html`: main portfolio page
- `resume.html`: printable resume page
- `inventory-app/`: browser inventory management demo
- `weather-app/`: weather search demo with API fallback
- `todo-app/`: local task manager
- `calculator/`: scientific calculator

## Environment Variables

- `WEATHER_API_KEY`: WeatherAPI key used by `api/weather.js`
- `RESEND_API_KEY`: Resend key used by `api/contact.js`
- `CONTACT_FROM_EMAIL`: optional sender address for the contact form
- `CONTACT_TO_EMAIL`: optional recipient address for the contact form
